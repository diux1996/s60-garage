S60 Garage – Terms and Privacy

Last updated: 10 November 2026

1. About the application

S60 Garage is a private iOS application developed by DIUX (Aykut Bulut) for personal use. It is used by one person only, the owner of the connected vehicle, and is not offered to the public, sold or distributed through any app store.

2. Purpose

The application connects to the Volvo Cars Connected Vehicle API to:

  • show the status of the owner's own vehicle (lock, doors, windows, tyres, fuel, odometer, service and warning information);
  • send remote commands (lock/unlock, climatisation, engine start/stop, honk/flash).

3. Data handling

  • Vehicle data is retrieved on demand and shown in the application only.
  • No vehicle or account data is stored on any server, sold, shared with third parties or used for analytics or advertising.
  • Access tokens, API keys and client credentials are stored only in the iOS Keychain on the owner's device.
  • Sensitive commands (unlock, engine start) require device authentication (Face ID or passcode).
  • The sign-in redirect page on this site only forwards the one-time authorisation code to the application and stores nothing.

4. Consent and revocation

Access is granted by the vehicle owner through Volvo ID sign-in. Consent can be revoked at any time by signing out in the application, by removing the connection in the application settings, or via the Volvo ID account.

5. Liability

The application is provided "as is" for personal use. The developer is not responsible for any damage resulting from the use of remote commands. Use is at the owner's own risk and must comply with local laws, for example regarding running an engine while the vehicle is unattended.
